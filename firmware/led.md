# Spresense Multi-IMU LED Status Documentation

## 概要

Spresense CXD5602PWBIMU UGV-Enhanced Firmwareは、4つの緑色LEDを使用してシステムの状態をリアルタイムで表示します。各LEDは異なるシステム要素の状態を示し、運用者がハードウェアレベルでシステムの健全性を即座に把握できるように設計されています。

## LED配置とラベル

```
[LED3] [LED2] [LED1] [LED0]
 左端   左中   右中   右端
```

## LED状態パターン定義

### 基本パターン
- **点灯**: 常時ON
- **消灯**: 常時OFF
- **ゆっくり点滅**: 1Hz（0.5秒ON/0.5秒OFF）
- **速い点滅**: 4Hz（0.125秒ON/0.125秒OFF）
- **ダブル点滅**: 0.2秒ON-0.2秒OFF-0.2秒ON-1.4秒OFF
- **パルス**: 呼吸パターン（サイン波状の明滅）

---

## LED0 - システム状態（右端）

| パターン | 状態 | 説明 |
|---------|------|------|
| **消灯** | 初期化中 | システム起動中、ハードウェア初期化実行中 |
| **ゆっくり点滅** | 待機中 | システム準備完了、キャリブレーション待ち |
| **点灯** | 正常動作 | システム正常稼働中、データ出力中 |
| **速い点滅** | システムエラー | 重大なシステムエラー、要確認 |

---

## LED1 - キャリブレーション状態（右中）

| パターン | 状態 | 説明 |
|---------|------|------|
| **消灯** | 未キャリブレーション | IMUキャリブレーション未実施 |
| **ダブル点滅** | キャリブレーション中 | 16-IMU統合キャリブレーション実行中 |
| **点灯** | キャリブレーション完了 | キャリブレーション成功、安定状態 |
| **パルス** | ドリフト警告 | キャリブレーションドリフト検出、要再校正 |

### キャリブレーション詳細
- **キャリブレーション時間**: 約3-5分
- **必要条件**: IMU静止状態
- **ドリフト検出**: 5分以上経過後に自動判定

---

## LED2 - データ品質（左中）

| パターン | 状態 | 説明 |
|---------|------|------|
| **消灯** | 品質不良 | データ品質率 < 50%、要対処 |
| **ゆっくり点滅** | 品質普通 | データ品質率 50-80%、通常使用可能 |
| **点灯** | 品質良好 | データ品質率 80-95%、推奨品質 |
| **速い点滅** | 品質優秀 | データ品質率 > 95%、最高品質 |

### 品質評価基準
- **品質率** = 良好サンプル数 ÷ (良好サンプル数 + 外れ値数)
- **評価要素**: ノイズレベル、温度安定性、振動影響
- **更新頻度**: リアルタイム（約190Hz）

---

## LED3 - 動作/エラー状態（左端）

| パターン | 状態 | 説明 |
|---------|------|------|
| **消灯** | 静止状態 | UGV静止中、動作検出なし |
| **ゆっくり点滅** | 緩慢動作 | UGV緩やかな動作中（低速移動・旋回） |
| **速い点滅** | 活発動作 | UGV活発な動作中（高速移動・急旋回） |
| **ダブル点滅** | エラー状態 | 連続外れ値検出、センサー異常の可能性 |

### 動作検出基準
- **静止判定**: 加速度変化 < 0.15G かつ 角速度 < 0.02dps
- **動作判定**: 加速度・角速度の変化量に基づく
- **エラー判定**: 50サンプル以上連続で外れ値検出

## 運用シナリオ別LED パターン

### 1. 正常起動シーケンス
```
起動時: 全LEDが順次点灯・消灯を3回繰り返し
初期化: LED0のみゆっくり点滅
キャリブレーション: LED0がゆっくり点滅、LED1がダブル点滅
完了表示: LED0、LED1、LED2が点灯（1秒間）
運用開始: LED0、LED1、LED2が点灯、LED3は消灯（静止時）
```

### 2. 正常運用パターン
```
静止時高品質: LED3消灯、LED2点灯、LED1点灯、LED0点灯
静止時普通品質: LED3消灯、LED2ゆっくり点滅、LED1点灯、LED0点灯
移動時高品質: LED3ゆっくり点滅、LED2点灯、LED1点灯、LED0点灯
移動時普通品質: LED3ゆっくり点滅、LED2ゆっくり点滅、LED1点灯、LED0点灯
高速移動時: LED3速い点滅、LED2点灯、LED1点灯、LED0点灯
```

### 3. 異常状態パターン
```
初期化エラー: 全LED速い点滅
センサーエラー: LED3速い点滅、LED2消灯、LED1速い点滅、LED0消灯
データ異常: LED3ダブル点滅、LED2消灯、LED1点灯、LED0点灯
キャリブレーション失敗: LED3消灯、LED2消灯、LED1消灯、LED0点灯
長期ドリフト: LED3消灯、LED2点灯、LED1パルス、LED0点灯
```

## トラブルシューティング

### LED0 がゆっくり点滅している場合
- **原因**: システムがキャリブレーション待ち状態
- **対処**: IMUを静止状態に保ち、キャリブレーション完了を待つ

### LED0 が速い点滅をしている場合
- **原因**: システムエラー（デバイスオープン失敗等）
- **対処**: システム再起動、ハードウェア接続確認

### LED1 が消灯している場合
- **原因**: キャリブレーション未実施
- **対処**: システム起動後、静止状態でキャリブレーション実行

### LED2 が消灯している場合
- **原因**: データ品質が著しく低い
- **対処**: 振動源除去、温度安定化、再キャリブレーション

### LED3 がダブル点滅している場合
- **原因**: 連続的な外れ値検出
- **対処**: センサー接続確認、環境ノイズ除去

---

## 状態判定フローチャート

### システム全体の健全性判定
```
LED0が点灯 → LED1が点灯 → LED2が点灯/点滅 → LED3が状態表示
    ↓           ↓           ↓               ↓
システム正常   キャリブ完了   品質良好         動作状態正常
```

### 異常時の優先対処順序
1. **LED0異常**: システム再起動
2. **LED1異常**: 再キャリブレーション
3. **LED2異常**: 環境改善
4. **LED3異常**: センサー点検

## 技術仕様

### 更新頻度
- **LED更新**: 20Hz
- **状態判定**: 約190Hz（10サンプルごと）
- **品質計算**: リアルタイム

### 電力消費
- **LED点灯時**: 約2mA per LED
- **LED消灯時**: 約0.1mA per LED
- **制御回路**: 約0.5mA

### 応答時間
- **状態変化検出**: < 100ms
- **LED反映**: < 50ms
- **品質計算**: < 10ms

## 運用上の注意事項

### キャリブレーション時
1. IMUを完全に静止状態に保つ
2. 振動源から離れた場所で実施
3. 温度が安定した環境で実施
4. LED1のダブル点滅中は移動させない

### 日常運用時
1. LED2の品質表示を定期的に確認
2. LED3のエラー表示時は即座に対処
3. 長時間運用時はLED1のドリフト警告に注意

### メンテナンス時
1. システム再起動時は起動シーケンスを確認
2. 異常パターン時はシリアル出力も併せて確認
3. 定期的な再キャリブレーションを推奨

## 実際の運用例

### 正常運用時の典型的なパターン

#### 起動直後
```
LED3: 消灯
LED2: 消灯
LED1: 消灯
LED0: ゆっくり点滅 ← システム初期化中
```

#### キャリブレーション中
```
LED3: 消灯
LED2: 消灯
LED1: ダブル点滅 ← キャリブレーション実行中
LED0: ゆっくり点滅
```

#### 運用開始（静止時）
```
LED3: 消灯 ← 静止状態
LED2: 点灯 ← 品質良好
LED1: 点灯 ← キャリブレーション完了
LED0: 点灯 ← システム正常
```

#### 移動時（高品質）
```
LED3: ゆっくり点滅 ← 緩慢移動
LED2: 点灯 ← 品質良好
LED1: 点灯 ← キャリブレーション完了
LED0: 点灯 ← システム正常
```

#### 高速移動時
```
LED3: 速い点滅 ← 高速移動
LED2: 速い点滅 ← 品質優秀
LED1: 点灯 ← キャリブレーション完了
LED0: 点灯 ← システム正常
```

### 異常時のパターン

#### データ品質低下
```
LED3: 消灯 ← 静止状態
LED2: 消灯 ← 品質不良、要対処
LED1: 点灯 ← キャリブレーション完了
LED0: 点灯 ← システム正常
```

#### センサーエラー
```
LED3: ダブル点滅 ← 連続外れ値検出
LED2: 消灯 ← 品質不良
LED1: 点灯 ← キャリブレーション完了
LED0: 点灯 ← システム正常
```

#### システムエラー
```
LED3: 速い点滅 ← 重大エラー
LED2: 速い点滅 ← 重大エラー
LED1: 速い点滅 ← 重大エラー
LED0: 速い点滅 ← 要再起動
```

## シリアル出力との対応

### 品質情報の読み方
シリアル出力: `# Quality: Good=1234, Outliers=56, Motion=0.8`

- **Good**: 良好サンプル数（LED2の点灯基準）
- **Outliers**: 外れ値数（LED3のエラー判定基準）
- **Motion**: 動作状態（0.0=静止、1.0=活発）

### LED状態とシリアル出力の関係
- LED2の点滅パターン ↔ Good/(Good+Outliers)の比率
- LED3の点滅パターン ↔ Motionの値
- 両者は同期して更新される

## 付録

### クイックリファレンス

| 状況 | LED3 | LED2 | LED1 | LED0 | 対処 |
|------|------|------|------|------|------|
| 正常運用 | 消灯/ゆっくり点滅 | 点灯/速い点滅 | 点灯 | 点灯 | なし |
| 品質低下 | 消灯/ゆっくり点滅 | 消灯/ゆっくり点滅 | 点灯 | 点灯 | 環境改善 |
| センサー異常 | ダブル点滅 | 消灯 | 点灯 | 点灯 | 点検 |
| システムエラー | 速い点滅 | 速い点滅 | 速い点滅 | 速い点滅 | 再起動 |

### 緊急時対応

1. **全LED速い点滅**: 電源再投入
2. **LED0のみ速い点滅**: ハードウェア接続確認
3. **LED3ダブル点滅**: センサー配線確認
4. **LED2消灯**: 振動・温度環境確認

### 点滅パターンの見分け方

- **ゆっくり点滅**: 1秒間隔で点滅（数えやすい）
- **速い点滅**: 0.25秒間隔で点滅（非常に速い）
- **ダブル点滅**: 短い点滅2回 → 長い消灯 → 繰り返し
- **パルス**: 緩やかに明るさが変化（呼吸のような）
